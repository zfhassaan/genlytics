Enterprise SOLID Architecture

Decoupled, extensible components designed for testability and zero downtime.

Repository Pattern

AnalyticsRepositoryInterface cleanly encapsulates the Google API Protobuf client. Mocking data in test suites requires zero GCP network calls.

Distributed Atomic Locks

Stale-While-Revalidate with atomic locks guarantees that only 1 worker refreshes an expired cache entry, preventing quota stampedes.

Queue Stampede Prevention

FetchAnalyticsDataJob implements ShouldBeUnique. Identical queries are debounced across your Redis or database queue.

Redis Cache Tagging

Automated cache tagging enables instant atomic invalidation via php artisan genlytics:refresh-cache --clear without flushing unrelated app cache.

Event-Driven Observability

Every query fires lifecycle events (Requested, Fetched, Failed) to feed custom metrics, logs, or WebSockets.

Dual Return Engines

Query as Collection for data transformation pipelines or JsonResponse for instant API responses.
